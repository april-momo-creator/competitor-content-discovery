# 03 Competitor Pool Layering

## Use When

Use after candidate discovery, or when the user provides a messy competitor list and needs it classified.

## Goal

Reduce candidates into a focused competitor pool for downstream positioning, differentiation, owned social, search-map, and content-candidate work.

## Gates

Keep a candidate if it satisfies at least 3 of 5 gates:

| Gate | Keep If |
|---|---|
| Problem relevance | Solves at least one core product problem |
| User relevance | Serves likely users, buyers, or influencers |
| Evidence sufficiency | Appears in at least two meaningful sources, or one strong explicit vs/alternative signal |
| Content researchability | Has observable social, UGC, review, creator, or community content |
| Actionability | Can inform differentiation, content topics, objections, or search terms |

## Competitor Types

| Type | Definition | Use For | Suggested Count |
|---|---|---|---|
| Direct competitor | Same user problem, similar core function/scenario, same buying decision | Positioning, selling points, rebuttal angles | 3-5 |
| Indirect competitor | Different category or workflow but solves the same pain/use case | Substitute paths, user objections, counter-positioning | 2-3 |
| Aspirational competitor | Audience overlaps and content/UGC is more mature, even if product differs | Content expression, formats, hooks, social tactics | 2-3 |

## Steps

1. Score each candidate against the five gates.
2. Remove weak or irrelevant candidates.
3. Assign each kept candidate to direct, indirect, or aspirational.
4. Prioritize the pool by relevance, evidence strength, and downstream usefulness.
